📡

بدون إنترنت

يعمل عبر نقطة الاتصال المحلية (Hotspot) بين الأجهزة ضمن مسافة تغطية الشبكة. لا حاجة لأي اتصال بالإنترنت على الإطلاق.

🔐

تشفير كامل

جميع المحادثات مشفرة بالكامل بين الأطراف المتصلة. يتم الاتصال عبر مسح QR Code مشترك لضمان الأمان.

📁

ملفات بلا حدود

أرسل أي نوع من الملفات بأي حجم — صور، فيديوهات، مستندات، وأكثر. بدون قيود على حجم الملف.

📞

مكالمات صوتية ومرئية

يدعم الاتصال الصوتي والفيديو بين الأطراف المتصلة عبر الشبكة المحلية بجودة عالية.

⚡

سريع الإرسال والاستلام

إرسال واستلام فوري للرسائل والملفات بسرعة فائقة عبر الاتصال المحلي المباشر بين الأجهزة.

👥

دردشة جماعية

أنشئ غرفة جماعية كمُضيف أو انضم كضيف. يدعم ربط عدة أجهزة معاً بضغطة واحدة.

📱

اتصال عبر QR Code

مسح باركود سريع وآمن للاتصال بين الأجهزة. أو أدخل عنوان IP يدوياً للاتصال المباشر.

📶

يعمل ضمن مسافة التغطية

يعمل التطبيق ضمن نطاق تغطية نقطة الاتصال (Hotspot). كلما كنت أقرب، كان الاتصال أسرع وأقوى.

خطوات بسيطة للبدء

ابدأ المراسلة المشفرة في ثلاث خطوات سهلة

1

اختر دورك

قم بإنشاء غرفة جماعية كمُضيف (Host) أو انضم إلى غرفة موجودة كضيف (Guest). يدعم ربط عدة أجهزة معاً بضغطة واحدة.

2

شارك الباركود

يقوم المُضيف بعرض باركود QR Code ومشاركته مع الأجهزة الأخرى للاتصال المشفر. أو يمكنك إدخال عنوان IP يدوياً.

3

ابدأ المراسلة

أرسل رسائل نصية، صور، فيديوهات، وملفات بأي حجم بسرعة فائقة. قم بإجراء مكالمات صوتية ومرئية. كل شيء مشفر وبدون إنترنت.
